# Portfolio - Srivathsan

Visual Storyteller, Photographer & Creator.

## 🚀 Features
- 3D Interactive Fan-Out Cards & Parallax Physics (GSAP + ScrollTrigger)
- High-Performance GPU-Optimized Gallery Lightbox Modal
- Categorized Photography Collections: Celebrities, Portraits, Events & Nature
- Responsive Dark Mode UI with Glassmorphism and Custom Micro-Animations

## 🛠️ Tech Stack
- React.js + Vite
- Tailwind CSS
- GSAP + ScrollTrigger
- Lucide React Icons

## 💻 Local Setup
```bash
npm install
npm run dev
```
